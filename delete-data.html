Delete your Utsav data

Utsav stores a local wedding plan on your device. If you have connected Utsav sharing or another family server, that service holds a separate shared copy. The default Utsav service is operated by Rajesh Ray and hosted with Fly.io in Singapore. Follow the steps for each copy you want removed.

Need help or no longer have the app?

Email iamrajesh350@gmail.com with the subject Utsav data deletion request. You can make this request without reinstalling Utsav.

Request deletion assistance

Say whether the data is on a device, on a family server, or in a previous support email. For a server request, include its website address and a non-secret wedding reference if you have one. Do not include owner keys, invitation keys, private RSVP links, passwords or a guest-list backup. Verification may be needed before anyone else's shared data can be removed.

For the default Utsav service, we can investigate a request and remove a shared wedding after verifying the requester’s authority. Support cannot remotely erase data stored only on your phone or independently operated servers. We can help identify the responsible wedding owner or server operator. A request is not confirmation that deletion has been completed.

If you use a family server

Delete the server wedding before removing the only owner's device access key. Disconnecting or uninstalling first can remove your ability to use the owner's deletion control.

  1. Open Settings & backups → Family sharing (advanced) on the owner's connected device.
  2. Choose Delete server wedding, read the confirmation, then choose Delete server wedding again. Wait for the success message.
  3. This removes that wedding from the running server's active database and makes its family access keys and guest RSVP links unusable. Copies previously downloaded to other devices or exported to files remain.
  4. If you are the owner and only want to remove this device’s connection, first choose Save a connection recovery file → Export private connection and keep that secret file protected. Then choose Disconnect device → Remove device access key. This removes the key here; it does not delete the server wedding or revoke copies of the key held elsewhere. Without a valid recovery file, you lose owner access. Family invitations only create editors.

An editor can choose Disconnect device → Revoke access and disconnect to invalidate that editor connection on the server and remove its key from this device. Copies of the same key stop working, but local wedding plans remain. An owner can choose Review family access, then Remove editor or Cancel invitation, and confirm with Revoke access. Revoking access does not erase plans already downloaded by that person. Guests should contact their wedding owner to remove guest details. If the owner has lost access, contact the server operator. For Utsav sharing, owner deletion immediately removes the active wedding and its access records. Encrypted daily hosting snapshots are configured to expire after five days, so a deleted wedding may remain in an earlier snapshot until it expires. Fly.io processes its own operational metadata. Other server operators control their own hosting logs, backups and retention; deleting a live room alone does not erase every provider record.

Delete plans on this device

  1. Export a wedding backup first only if you want to keep a copy.
  2. Open Settings & backups → Delete data on this device.
  3. Read the confirmation and choose Confirm. Wait for Utsav to report that local plans were deleted.

This clears locally saved wedding details, guests, celebrations, vendors, budget records, tasks and family assignments. It also cancels scheduled task reminders and removes Utsav's temporary export files. A fictional sample wedding then appears; it is not your deleted wedding.

The optional family-server connection is managed separately. Follow the disconnect steps above to remove its access key from this device. If an operation fails, the app reports the problem; retry rather than assuming deletion succeeded.

Remove other copies

  • Delete JSON wedding backups, private connection recovery files and CSV guest exports from Downloads, Files, cloud drives, email and messaging apps where you saved them. Deleting a recovery file alone does not revoke its server key. Use Replace this device’s access key → Replace access key to invalidate old copies of the current key, then save a new recovery file if you need one.
  • Ask recipients to delete copies you shared with them. Utsav cannot recall a file or message already sent.
  • Review device or cloud backups you control. Their retention and deletion are governed by the relevant provider.

Restoring an old wedding backup will restore the personal details contained in that file. Keep only the copies you intend to retain.

Information in support messages

If you previously emailed Utsav support, you may request deletion of that correspondence by emailing from the same address and identifying the conversation. Email services may keep their own operational or backup records. The five-day setting applies to Utsav family-service snapshots, not email-provider records. Ask the responsible provider about the records involved in your request.
